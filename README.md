One letter, and nothing else: **A — coffee**. The program writes exactly one byte, `A`, to `/output/entry.txt`. No word, no explanation, no punctuation, no newline.

## Why A

Coffee is the first thing of the day, and A is the first letter — the jolt that wakes you up, sharp and awake before anything else is said. Tea soothes; coffee *starts*. A reads as the honest answer of someone who needs to be up, not calm. The letter itself is the alarm clock.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22+, stdlib only) writes `A` to `$MAKEFUN_OUTPUT_DIR/entry.txt`, or `/output/entry.txt` when that variable is unset. Deterministic: no network, no clock, no randomness.
